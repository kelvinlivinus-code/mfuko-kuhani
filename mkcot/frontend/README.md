# MKCOT: frontend

Kurasa za mfumo wa MKCOT (Mfuko wa Kuhani wa Operation and Training).

## Kuendesha kwenye kompyuta yako

```bash
npm install
npm start            # http://localhost:4200 (API inapelekwa kwa backend kupitia proxy.conf.json)
```

## Kujenga kwa matumizi halisi

```bash
npm run build        # matokeo yanakuwa kwenye dist/
```

Kwa maelezo kamili ya mfumo mzima angalia `../README.md`.
